# DISI 057 release plan: benchmark bWAR evidence

This is evidence recovery, data and provenance only. It adds Baseball-Reference team-season bWAR for the eleven mature benchmark MLB reachers
whose bWAR labels were NULL only because their WAR was not loaded. The rows are read from archived copies of the two data files DISI already
cites. The benchmark positive-bWAR reference baseline becomes supported as a result of that evidence, under unchanged thresholds. **No fitted
model becomes supported.**

**Not applied to production.** Applying it, merging the PR and any deploy need explicit owner approval. Production is at 056 (generation 12,
259/259), and 056 is frozen. Baseline `main` is `0141ff68e024d374bf73b9ca96b17a85ceeaa513`, which includes the verifier hardening.

## Rollback

`rollback-057.sql` runs in one guarded transaction. It refuses unless 057 is applied. It also refuses if later research depends on the 057
evidence: a superseding fact, a different career bWAR, or a later bWAR evaluation. It then:

- **retracts** exactly the 54 rows, because the 032 guard forbids deleting a team-season fact; retracted facts are sealed and read by nothing;
- sets the eleven `career_war` values back to NULL;
- removes the six bWAR evaluation rows. The reach rows were never touched, and this is proved;
- proves that the active rows, support, labels and stored evaluation are exactly the pre-057 state;
- refreshes once.

The sources stay as provenance. **057 can be applied again after its rollback**: it inserts fresh active rows beside the retracted ones.

Roll 057 back before any earlier benchmark rollback. `rollback-050` refuses once any team-season row, active or retracted, exists for a player it
covers, and it covers all eleven. It is therefore unavailable after 057 has been applied once. `rollback-055` and `rollback-056` are unaffected.
