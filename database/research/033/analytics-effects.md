## Downstream flag

`DOWNSTREAM_ASSET_CHAIN_INCOMPLETE` rises from 0 to 20 tracked signings because return assets now have recorded later exits. This is improved factual completeness, not a defect; the flag is deliberately not suppressed and no downstream value is credited (Migration 034).

## Two kinds of change

A. **New facts** (what actually happened): Rincon, the cash-only and no-player-return trades, the trade packages for signings that were previously unmodeled, and the downstream flags.

B. **Absent return WAR rows**: loading the 40 return persons (573 team-season rows) in the same migration prevents 14 sole-attributable events from being `RETURN_WAR_UNKNOWN`. Without that load the aggregate would have been computed on a smaller denominator.
